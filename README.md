**# JiguangPhantom**



**Repository for the Robbyant Embodied AI Challenge.**



**## Base Model**



**LingBot-VLA 2.0**



**## Simulator**



**RoboTwin 2.0**



**## Repository Structure**



**- `configs/`: training and evaluation configurations**

**- `scripts/`: setup, training, and evaluation scripts**

**- `src/`: team-developed code**

**- `experiments/`: experiment records and results**

**- `docs/`: team documentation**

**- `third\_party/`: external repositories or submodules**

**- `data/`: local datasets, not tracked by Git**

**- `models/`: local model weights, not tracked by Git**

**- `outputs/`: checkpoints and experiment outputs, not tracked by Git**

**- `logs/`: training and evaluation logs, not tracked by Git**



**## Competition Constraint**



**Only competition-designated RoboTwin 2.0 clean data may be used for training.**



**Randomized data must not be used for training.**
